# Applying a brand profile

## Scene-level application

- Text scenes: apply brand typography, palette, copy voice, spacing rhythm, and signature motion.
- Product scenes: preserve product fidelity; apply brand direction through framing, callouts, transitions, cursor treatment, and pacing.
- Feature callouts: use the approved accent policy and terminology.
- Comparisons: preserve consistent scales and use approved positive/negative language.
- Logo outro: use only approved assets, backgrounds, motion, audio, and hold durations.

## Restraint

Choose one dominant branded behavior per scene. Supporting motion should reinforce it. Do not turn every brand adjective into a simultaneous visual effect.

## Conflicts

When a campaign brief departs from the profile, record the exception with scope and duration. Do not silently rewrite the reusable profile from one campaign request.

## Missing values

If the profile lacks a decision:

1. Preserve the existing product or campaign treatment.
2. Use accessible, restrained defaults.
3. Ask the owner when the choice materially changes brand recognition.
4. Record the confirmed answer for future productions only with permission.
